# Neon Courier

A tiny arcade game built with vanilla HTML, CSS, and JavaScript for Global Hack Week.

## Play locally

Open [index.html](./index.html) in a browser. No build step or dependencies are required.

## How to play

- Move with `Left` / `Right` or `A` / `D`.
- Avoid the pink data blocks.
- Collect yellow sparks for bonus points.
- Your best score is saved in the browser.
